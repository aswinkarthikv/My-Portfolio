## 🏛️ Overview

This portfolio is an immersive, dark-aesthetic, cinematic web experience designed to showcase enterprise-grade software engineering, AI systems, full-stack architecture, and cybersecurity projects with smooth physics-based interactions and luxury visual design.

---

## ✨ Key Features & Architectural Highlights

- **🎬 Ambient Cinematic Video Hero**: Seamless blend of ambient looping background video with film grain overlay and interactive fluid custom cursor physics.
- **🪞 3D Holographic Tilt Portrait**: Perspective-transformed about card responding dynamically to real-time mouse movements with light-sweep shaders and gold embers.
- **🃏 React Bits Scroll Stacking Deck**: Interactive depth-scaled project deck featuring corner brackets, monoline typography, and metric telemetry.
- **⚡ Tech Matrix Bento Grid**: Glassmorphic bento blocks highlighting core software engineering, backend APIs, database architectures, and Generative AI competencies.
- **🗺️ Interactive Route Map Timeline**: Animated golden laser timeline tracking educational milestones and professional advisory journey.
- **📡 Monolith Terminal Dispatch Form**: Functional, direct email dispatch integration via FormSubmit with real-time packet state feedback.
- **🚀 100% Automated CI/CD**: Automatic production build and deployment to GitHub Pages via GitHub Actions workflow.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### Installation & Development

```bash
# 1. Clone the repository
git clone https://github.com/aswinkarthikv/My-Portfolio.git

# 2. Navigate to project directory
cd My-Portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Building for Production

```bash
npm run build
```

The optimized static assets will be generated in the `dist/` directory.

## 📦 Deployment

This repository includes a dedicated **GitHub Actions workflow** (`.github/workflows/deploy.yml`). 
Whenever changes are pushed to the `main` branch, the workflow automatically builds the project and deploys it directly to GitHub Pages.
